
# GamesBuster

GamesBuster è un'applicazione web concentrata sul mondo del gaming. Si passa dalla parte di e-commerce di videogiochi, dai giochi fisici e digitali fino ai bundle, ad una esperienza completa di cloud gaming, trade in da utenti e un forum da utilizzare per potersi confrontare su qualsiasi espeirenza videoludica tra giocatori




## Installation

Per installare il progetto correttamente, aprire il terminale, posizionarsi nel folder e digitare i seguenti comandi:

N.B: è necessario avere Node.js installato sulla macchina per poterlo usare

```bash
  npm install

  // Dopo aver installato le dipendenze

  npm run dev

  // Copiare e incollare il link del localhost
```
